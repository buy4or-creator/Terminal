# Terminal

Современный эмулятор терминала для Windows на базе **Qt / C++** и **Windows ConPTY** с поддержкой 256-цветного вывода, SSH/nano, быстрых командных биндов и бесконечной доски визуальных заметок.

## 📥 Установка (Windows x64)
1. Перейдите в раздел **[Releases](https://github.com)**.
2. Скачайте **`Terminal-Setup.exe`** и запустите установку.

## ✨ Основные возможности
- **Нативный Windows ConPTY + VT100/xterm-256color**: корректная работа `cmd`, `PowerShell`, `ssh`, `docker compose`, `neofetch` и `nano` с поддержкой альтернативного буфера экрана (`?1049h`).
- **Настраиваемый курсор и темы**: выбор формы курсора (`Блок █`, `Подчёркивание ▁`, `Черта ▏`), 6 цветов курсора и 8 цветовых тем оформления.
- **Панель быстрых биндов**: сохранение и запуск частых команд и SSH-подключений в один клик.
- **Интерактивные заметки (Mind-Map & Canvas)**: бесконечное полотно с сеткой, карточки со связями, свободное рисование кистью с палитрой, точечный ластик и защита доступа 4-значным PIN-кодом.

## 🛠 Сборка из исходников
1. Откройте `console-v1.pro` в **Qt Creator** (Qt 6.x, MinGW 64-bit).
2. Выберите конфигурацию **Release** и нажмите **Ctrl + B**.
