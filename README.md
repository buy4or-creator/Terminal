# Terminal — v2.0

Кроссплатформенный терминал для **Windows** и **Linux** на **Qt 6 (C++)** с интерфейсом Apple Liquid Glass.

## Возможности
- **Терминал**: вкладки на ConPTY/PTY, ANSI-цвета, видимый курсор, копирование и вставка.
- **SSH/SFTP-проводник**: интерактивная авторизация ключом или паролем, навигация по папкам, загрузка и скачивание файлов, контекстные действия.
- **Доска заметок**: несколько полей, карточки с изменяемым размером, связи, медиа-вложения и голосовые сообщения с управлением воспроизведением.
- **Настройки и внешний вид**: стеклянные панели, темы, живые превью и параметры заметок.
- **Окно без рамки**: ручка заголовка для перемещения и адаптивные панели.

## Сборка

Требуются Qt 6 и компилятор MinGW (Windows) либо GCC (Linux).

```powershell
qmake console-v1.pro CONFIG+=release
mingw32-make -f Makefile.Release -j4
```

Для Windows-сборки Qt можно развернуть рядом с исполняемым файлом командой `windeployqt --release release/console-v1.exe`.
