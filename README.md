# Terminal — v1.2 (beta)

Современный кроссплатформенный терминал для **Windows** и **Linux** на **Qt 6 (C++)** в стиле **Apple Liquid Glass**.

## Основные возможности v1.2 (beta)
- **Интерфейс Apple Liquid Glass**: матовое полупрозрачное стекло, плавные анимации, индикаторы активного раздела, сворачиваемая панель пользовательских биндов и живое превью в настройках.
- **Полноценный PTY / ConPTY терминал**: поддержка вкладок с переименованием, копированием/вставкой по ПКМ, ANSI-цветами и режимами курсора.
- **Выбор шрифта терминала**: базовый шрифт за разделительной чертой и 15 моноширинных шрифтов с возможностью закрепления (`📌`) любимых шрифтов наверху списка.
- **Встроенный SFTP-проводник по SSH**:
  - Одноразовое окно подключения по паролю или SSH-ключу, список недавних серверов.
  - Интерфейс в стиле проводника с деревом быстрого доступа, историей навигации (`←`, `→`, `↑`), живым поиском по папке, загрузкой и скачиванием файлов.
  - Контекстное меню по правой кнопке мыши: открытие файла в `nano` в консоли или на ПК, переименование, перемещение, вырезание/вставка, упаковка в `.tar.gz`, создание папок и удаление.
- **Интерактивная доска заметок**: карточки с бесконечным изменением размера, связями между заметками, настройкой базового размера плашек и максимального отдаления холста.

## Установка
Скачайте готовый архив для **Windows (x64)** или **Linux (x64)** из раздела **[Releases](https://github.com)**.
