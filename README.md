# Terminal

Современный кроссплатформенный эмулятор терминала для **Windows** и **Linux** на базе **Qt 6 / C++** с поддержкой 256-цветного вывода, SSH/nano, быстрых командных биндов и бесконечной доски визуальных заметок.

## 📥 Установка

### Windows (x64)
1. Перейдите в раздел **Releases** справа на странице репозитория.
2. Скачайте **Terminal-Setup.exe** и запустите установку *(при первом запуске Windows SmartScreen нажмите «Подробнее» → «Выполнить в любом случае»)*.

### Linux (x64)
1. Скачайте **Terminal-Linux-x64.tar.gz** из раздела **Releases**.
2. Установите зависимости Qt 6 (для Ubuntu/Debian) и запустите:
```bash
sudo apt install -y libqt6widgets6 libqt6gui6 libqt6core6
tar -xzf Terminal-Linux-x64.tar.gz
cd Terminal-Linux-x64
./Terminal
```

## ✨ Основные возможности
- **Нативный ConPTY (Windows) + PTY (Linux)**: корректная работа `cmd`, `PowerShell`, `bash`, `zsh`, `ssh`, `docker compose`, `neofetch` и `nano` с поддержкой альтернативного буфера экрана (`?1049h`).
- **Настраиваемый курсор и темы**: выбор формы курсора (**Блок █**, **Подчёркивание ▁**, **Черта ▏**), 6 цветов курсора и 8 цветовых тем оформления.
- **Панель быстрых биндов**: сохранение и мгновенный запуск частых команд и SSH-подключений в один клик.
- **Интерактивная доска заметок**: бесконечное полотно с сеткой, карточки со связями (отмена по `Esc`), кисть с палитрой и толщиной, точечный ластик (`Ctrl + Z`) и защита 4-значным PIN-кодом.

## 🛠 Сборка из исходников

```bash
make -j4
```
